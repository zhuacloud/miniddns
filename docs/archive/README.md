## 为什么归档而不是删除

1. 规格正文是"实现的唯一依据"，需要能回答"这条约束是从哪来的、原文怎么写的"；
2. v1.2 的修订项需要对照原始措辞才能确认没有曲解原意；
3. 快照的 sha256 固定可校验，避免"文档被悄悄改过"的争议。
